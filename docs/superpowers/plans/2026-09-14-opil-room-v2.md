# OPIL Class Room v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The class room looks and flows like the concept boards — state in words, one obvious action, a question queue with Bring on stage, a "You're in the right place" join screen — on desktop and phone, with a one-line switch back to today's room.

**Architecture:** `js/rtk-room-v2.js` composes RealtimeKit's components (`rtk-ui-provider`, `rtk-grid`, `rtk-chat`, `rtk-participants`, `rtk-polls`, `rtk-breakout-rooms-manager`, `rtk-participants-audio`, `rtk-notifications`, `rtk-dialog-manager`) inside our own HTML (join screen, Now strip, word-chip toggles, Ask-a-question queue, Ready-to-speak panel, Tools sheet, mobile bottom sheet). Pure decisions live in `opil/hub/live-rooms.js` (tested with `node --test`). The queue is a Supabase table with realtime. `js/rtk-room.js` (v1 shell) is untouched and selected by `?classic=1` or `ROOM_V2 = false`.

**Tech Stack:** RealtimeKit core 2.0.2 (IIFE) + UI kit 2.0.2 (ESM from jsdelivr, pinned), supabase-js v2, Postgres RLS, static pages stamped by `build_site.py`, `node --test`, Playwright harness (stubbed hub.js + stubbed kit), real-room check with Claude in Chrome.

**Spec:** `docs/superpowers/specs/2026-09-14-opil-room-v2-design.md`

## Global Constraints
- Nothing server-side that the v1 room depends on changes (`ea-rtk-join`, `ea-rtk-record`, chat policies, replays).
- v1 stays reachable: `?classic=1` always mounts `rtk-room.js`; `ROOM_V2` constant flips the default.
- Copy rule: words over icons; every state readable as a sentence; no jargon.
- Brand tokens from the spec; targets ≥ 48px; phone ≤ 720px is one column with a fixed bottom bar (safe-area inset).
- `build_site.py`: add `js/rtk-room-v2.js`, `css/rtk-room-v2.css` to the hash list AND `_ASSET_RX`; bump `sw.js`.
- Migration `0035` additive; applied via Nelson's `!` script.
- Commit trailer on every commit (Co-Authored-By + Claude-Session lines as in this session).
